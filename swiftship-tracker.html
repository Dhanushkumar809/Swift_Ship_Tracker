SwiftShip Tracker

A Salesforce parcel booking and tracking system. A customer gives the Agentforce agent a parcel ID and gets the status, weight and estimated delivery date back from the Parcel record.

The demo runs on sample data in this page. In the project the agent calls the Parcel Details flow, which reads Parcel__c.

Problem and users

Customers book parcels through support calls or several apps, and have no simple way to see where a parcel is. Agents update status by hand and admins cannot see operations in one place.

Who uses it

Customer / sender

Books parcels, tracks them, receives updates through Experience Cloud or the AI agent.

Delivery agent

Moves a parcel from Booked to Delivered and keeps the current location up to date.

Support and admin

Support resolves delivery issues through Cases. Admins manage roles, security and dashboards.

Technology stack

Data model

Sender and Receiver both link to Parcel. Delivery links to Parcel and Sender and holds the live location.

Automation and AI

A parcel moves through four statuses. Flows update it, email alerts tell the customer at each stage, and Batch Apex handles periodic updates.

Agent flow: Parcel Details

StartAuto-launched, input: ids
Get RecordsParcel where Parcel_ID__c = ids
ActionRetrieve Parcel Details prompt
AssignmentOutput = prompt response
End

Prompt template: Retrieve_Parcel_Details

Retrieve details from Parcel__c where Parcel_ID__c matches user input.

Parcel Tracking Update
- Parcel Name: {!$Input:Parcel__c.Name}
- Parcel ID: {!$Input:Parcel__c.Parcel_ID__c}
- Status: {!$Input:Parcel__c.Status__c}
- Weight: {!$Input:Parcel__c.Weight__c}
- Estimated Delivery Date: {!$Input:Parcel__c.Estimated_Delivery_Date__c}

The flow is attached as an action on the Parcel Updates subagent, so the agent can call it when a customer asks about a parcel.

Automation inventory

Record-triggered, auto-launched and scheduled flows. Approval processes. Apex classes for parcel and delivery actions, and Batch Apex for periodic updates. Email templates for booking confirmation, delivery updates and completion.

Security

Administrator→Delivery Manager→Agent→Customer

Sharing rules on Parcel__c and Delivery__c control agent and manager access. Customers only see records linked to their own Sender or Receiver details.
